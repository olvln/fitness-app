# 健身记录（手机网页版）

一个零依赖、零构建、单文件的健身训练记录 Web App。手机浏览器打开就能用，也可以「添加到主屏幕」当 App 用。

数据全部存在手机浏览器本地（`localStorage`），不需要账号、不需要服务器、不联网也能用。

在线使用：<https://olvln.github.io/fitness-app/>

## 功能特性

- **训练日循环**：不绑星期，按「训练日 A/B/C」循环推进，今天练完自动轮到下一个训练日；预置「推 / 拉 / 腿」三天模板，随时可改。
- **分化与动作自主编辑**：训练日里增删动作、改目标组数、次数区间、每个动作自己的组间歇秒数；动作名从内置动作库（36 个常见中文动作）里自绘弹层选择，也能自己加新动作。
- **一键记组**：点某组的 ✓ 即记录该组，重量/次数默认沿用上次同动作同序号的数值，只需确认或微调。
- **自动组间歇计时**：完成一组自动开始倒计时，到点提示音 + 震动；支持 `+15s` 与 `跳过`；再点一次已完成的 ✓ 可撤销（同一组 0.3 秒内连点会被忽略）。
- **真实休息回写**：开始下一组时，把上一组与这一组之间真实经过的秒数写进记录（按时间戳计算，不靠计数累加，切后台回来依然准）。
- **月历与历史**：本月哪几天练了、那天练的哪个分化，点进去看每个动作每一组的重量×次数和实际休息秒数。
- **动作统计**：每个动作的历史最佳重量、总组数、总容量。
- **数据导出 / 导入**：导出 `fitness-backup-YYYY-MM-DD.json`，导入时可选「合并」（本机已有日期保留不动，只补缺失记录，幂等）或「覆盖」；解析失败会回滚并说明原因。
- **移动端优先**：竖屏布局、触摸目标 ≥ 44px、无横向滚动；训练中尽量申请屏幕常亮（Wake Lock）。
- **零依赖**：没有 npm 包、没有构建步骤、没有 CDN 外链，`index.html` 一个文件就是全部逻辑。

## 本地运行

不需要安装任何依赖，用任意静态服务器指向仓库根目录即可：

```bash
python -m http.server 8000 --bind 0.0.0.0
```

然后用浏览器打开 `http://localhost:8000/`。

想在手机上用（局域网访问）：手机连同一个 WiFi，先查电脑的局域网 IP——Windows 用 `ipconfig` 看 WLAN/以太网的「IPv4 地址」，macOS/Linux 用 `ifconfig` 或 `ip addr` 看 `en0` / `wlan0` 的 `inet` 地址——然后手机浏览器打开 `http://<电脑的局域网IP>:8000/`。

Windows 首次运行会弹防火墙提示，点「允许访问」。IP 会随网络变化，换网络后重新查一次即可。

想更接近原生 App：浏览器菜单里选「添加到主屏幕」，会以独立窗口打开并显示图标。

## 用法

- 训练页：默认显示下一个训练日，点「开始训练」进入当次训练。点某组的 ✓ 即记录该组，同时自动开始组间歇倒计时；顶部计时条可 `+15s` / `跳过`。
- 点「完成训练」写入历史，并把循环指针推进到下一个训练日。
- 日历页：练过的日子是绿色，点日期看当天每组明细。
- 统计页：每个动作的最佳重量、总组数、总容量。
- 设置页：编辑训练日的动作/组数/次数区间/休息秒数，管理动作库，改默认组间歇，导出/导入数据。

## 项目结构

```
.
├── index.html              # 全部界面与逻辑（单文件，无依赖，无外链）
├── manifest.webmanifest    # PWA 元数据，用于「添加到主屏幕」
├── icon.svg                # 应用图标（SVG）
├── LICENSE
└── tests
    ├── check.js            # 流程测试：用最小 DOM 桩跑 index.html 的真实逻辑
    └── check_html.py       # 结构检查：HTML 标签是否配对
```

### 测试

```bash
node tests/check.js        # 完整流程测试，全绿输出「全部通过」
python tests/check_html.py # 标签配对检查
```

两个脚本都以自身位置定位 `index.html`，在任意工作目录下运行都可以。`check.js` 也支持用 `HTML=<某个 html 路径>` 指到别的版本上跑，用来验证用例本身能不能抓到旧 bug。

另外 `index.html?selftest=1` 会在页面上跑内置自检（数据迁移、训练日循环、休息换算、容量统计、同日两次训练累加、备份导入 / 损坏 JSON / 空对象），直接显示 PASS/FAIL。

## 数据安全

- 所有数据只存在手机浏览器的 `localStorage`（键 `fitness.v1`）。**清浏览器数据、换浏览器、换手机、用无痕模式都会丢**，无痕模式下关闭页面即丢。
- 请定期在「设置 → 数据备份 → 导出数据」保存 `fitness-backup-YYYY-MM-DD.json`。
- 恢复或迁移：把备份文件传到新设备，用「导入数据」选择它，再选：
  - **合并**：本机已有的日期保留不动，只补进本机没有的日期和训练日（重复导入同一份备份不会产生重复记录）。
  - **覆盖**：完全替换本机数据；正在进行的训练会被丢掉（会先弹确认）。
- 导入前会先在内存里备份当前数据，解析失败或写入异常会回滚并提示原因；损坏 JSON、缺字段、版本不匹配都会给出明确提示，不会白屏。
- 导出文件是明文 JSON，包含你的全部训练记录，别随手发给别人。

## 已跳过 / 已知限制

- **PWA 离线缓存（Service Worker）**：部署在 https 上是安全上下文，技术上可以注册，但本版本没做，只用 manifest + 图标实现「添加到主屏幕」。页面本身零外链，浏览器缓存命中时断网也能打开，但没有可靠的离线缓存层。
- **云同步**：需要后端 + 账号，当前用导出/导入代替备份与迁移。
- **系统通知**：组间歇提醒只有页面内提示音 + 震动。在 https 下可以申请通知权限，本版本还没做。
- **锁屏 / 切后台提示音会延迟**：浏览器会暂停后台页面的脚本。倒计时本身按时间戳计算（回到页面时剩余时间仍然正确），但提示音要等你回到页面那一刻才响。训练时建议保持页面在前台，并把手机自动锁屏时间调长。
- **提示音需要先点一下**：浏览器要求先有用户操作才允许播放声音，所以首次进训练页会看到「点任意处启用提示音」，点过任意位置后本次会话内不再提示。
- **主屏幕图标**：Android 用 manifest 里的 SVG 图标；iOS 不支持 SVG 图标，主屏幕图标会是页面截图。
- **Wake Lock（屏幕常亮）**：只在安全上下文可用。https 部署后可用；局域网 http 下浏览器不提供，会自动跳过且不报错。
- **跨 0 点的训练算开始那天**：比如 23:50 开始、0:20 结束，记录在 23:50 那一天。
- 单位固定 kg，单人单设备，不做账号 / 多用户。
